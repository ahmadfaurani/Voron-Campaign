## Methodology

### Sources Used
1. **Official institution websites** — leadership pages, board of directors, key management, senior management team pages
2. **Annual reports** — Bursa Malaysia filings, corporate governance statements, financial statements
3. **Firecrawl MCP** — scraping, mapping, extraction, and autonomous agent browsing
4. **web_extract** — fallback scraping for JS-blocked pages
5. **web_search** — supplementary discovery (limited effectiveness for Malaysian-specific queries)
6. **LinkedIn** — site:linkedin.com searches for role verification
7. **Industry sources** — ASEAN Risk Awards, Star Cybersecurity Summit, TheOfficialBoard, TheOrg
8. **Firecrawl agents** — autonomous browsing for JS-rendered sites (Alliance Bank, AmBank, HLB)

### Confidence Scoring
- **conf 95**: Verified via official source (website, annual report, Bursa filing)
- **conf 85**: Verified via credible secondary source (Wikipedia, industry conference)
- **conf 80**: Inherited from parent entity with documented precedent
- **conf 75**: Group-level attribution (foreign bank subsidiary)
- **conf 40-45**: Confirmed absence (role checked and not found on official page)
- **conf 20-30**: Likely absent but source access limited (DNS failure, 404, JS rendering)

### Search Exhaustion Protocol
Each institution was researched through:
1. Direct URL extraction (official leadership page)
2. Site mapping (find leadership/management/board pages)
3. Annual report / corporate governance statement extraction
4. Web search for institution + role + year
5. LinkedIn search (site:linkedin.com/in)
6. Firecrawl agent (autonomous browsing for JS-rendered sites)
7. Source documentation (every gap recorded with source + date + reason)
